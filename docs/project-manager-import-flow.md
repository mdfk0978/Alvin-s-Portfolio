# 專案清單與匯入比對流程（草案）

## 目標
- 專案清單來源：
  - 從「輸入端」新增任務時，自動新增/更新專案清單。
  - 從「匯入資料」時，自動掃描匯入內容並建立專案清單。
- 匯入時比對任務是否已存在，避免重複。
- 針對「疑似新任務」提供勾選視窗，由使用者決定是否新增。

## 專案清單自動維護規則
1. **新增任務時**
   - 當使用者在輸入端提交任務：
     - 若「專案名稱」不存在於專案清單，新增一筆專案。
     - 若已存在，則更新最近使用時間（可選）或忽略。
2. **匯入任務時**
   - 先掃描匯入資料的「專案名稱」欄位。
   - 將匯入內容中的專案名稱與專案清單比對：
     - 若不存在，則新增該專案。
     - 若存在，則維持原設定（顏色/標籤不變）。

## 匯入任務比對流程
1. **上傳檔案**（支援 Excel/CSV）。
2. **解析匯入資料**：轉換為標準欄位（例如：專案名稱、負責人、任務說明、開始/截止日期等）。
3. **任務比對**：
   - 以「專案名稱 + 任務說明 + 開始/截止日期」作為主要比對鍵（可再加入負責人、對象等欄位增加準確度）。
   - 若比對成功，視為「已存在」。
   - 若比對失敗，視為「疑似新任務」。
4. **勾選視窗**：
   - 顯示所有疑似新任務。
   - 預設可全選/取消全選。
   - 使用者勾選後送出，才會新增進資料庫。
5. **新增結果回饋**：
   - 顯示成功新增數量與略過數量。
   - 保留匯入記錄（可選）。

## 勾選視窗內容建議
- 顯示欄位：
  - 專案名稱
  - 任務說明
  - 負責人
  - 開始/截止日期
  - 對象
- 操作：
  - 全選 / 全不選
  - 確認新增 / 取消

## 使用者體驗說明（白話）
- 只要你在表單輸入新的「專案名稱」，系統會自動把它加入專案清單，不需要另外維護。
- 匯入 Excel/CSV 時，系統會先比對是否已經存在，避免重複。
- 若系統判斷為「可能是新任務」，會彈出勾選視窗，讓你勾選要新增的項目，確保不會誤新增。

## 後續可選功能
- 任務比對規則可提供「嚴格/寬鬆」模式（例如是否必須日期完全相同）。
- 匯入前自動預覽，讓你先檢查欄位是否正確對應。
- 支援匯入後自動分派顏色（若專案未設定顏色）。
